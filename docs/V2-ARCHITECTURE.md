# V2 — аудит и архитектура

Исходная точка: commit 7fc66e1, локальный Git-тег backup/v1-before-boris-20261031. До изменения исходников выполнены 18 тестов движка, 6 PWA-тестов, 11 production-браузерных сценариев и production build; всё успешно. Публичный Pages вернул HTTP 200.

## Контракт сохранения V1

Не меняются: src/engine.js, src/content.js, ключ absurd-os:universe:v1, шесть протоколов, 142 миниатюры, восемь достижений V1, три секрета, последние 150 записей, архив, отчёт, подтверждённый перезапуск, Clipboard fallback, настройки и PWA scope /absurd-os/.

V1 engine остаётся чистым ядром. V2 src/world.js — совместимый композиционный слой: читает старые данные, вызывает валидатор V1, добавляет явно валидированные поля V2, пишет по тому же ключу. На первой успешной миграции создаёт необязательную резервную копию исходного V1 JSON. Сбой резервного копирования не прерывает чтение. Достижения V2 хранятся отдельно: старые имена и допуски не теряются. Повторная миграция идемпотентна.

## Модули

- src/boris.js и boris-content.js: персонаж, ограниченная история, контекст, локальные ответы без интернета. Не меняют мир.
- src/experiments.js: каталог риска/вероятностей; только известные команды и детерминируемые RNG-результаты.
- src/world.js: миграция, V2-достижения, применение результатов через V1 applyEvent, ограниченные системные события. Произвольный текст не является командой.
- src/BorisLab.jsx: отдельная область #boris, аватар, чат, эксперименты с подтверждением, честный AI/local-статус.
- src/audio.js: звуковые профили, громкость, отдельные каналы; выключены по умолчанию.
- src/ai-client.js: отмена/таймаут и безопасный JSON-контракт; ошибка переводит к локальному Борису.
- worker/: опциональный Cloudflare Worker, серверные секреты, CORS и Durable Object лимиты. Без реального развёртывания AI не объявляется подключённым.
- src/pwa.js и vite.config.js: существующий жизненный цикл SW остаётся prompt-based; новые локальные модули входят в build/precache.

## UI и жизнь системы

Пульт V1 остаётся на месте. Отдельная рабочая область Бориса открывается по hash #boris, работает на Pages без серверного роутинга. Редкие события планируются только при видимой странице, не чаще заданного интервала, без догоняющей генерации после сна. Новые результаты в архиве маркируются полями origin/risk/outcome; сохраняются через явную валидацию.

Финал 100% остаётся недопускающим закрытие без перезапуска, с вмешательством Бориса. Анимации ограничены камерой/аватаром; effects=false и prefers-reduced-motion подавляют движение.

## Приёмка

Регрессия V1 неизменными тестами; миграция полного V1 fixture; повреждённые вложенные поля; ограничение чата и архива; неизвестные/AI-команды без изменения мира; успешные/провальные/редкие эксперименты через RNG; отказ/таймаут AI; уровни камеры; опасный эксперимент требует согласия; reload и offline Борис; реальные обновления SW. Установка с иконки на физических iPhone/Android не подменяется эмуляцией браузера.
