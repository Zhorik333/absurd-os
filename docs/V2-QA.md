## Существенные сценарии

- Все шесть протоколов V1, 142 исходных события, секреты и достижения остаются на месте.
- Полное сохранение V1 переносится в V2; исходный JSON копируется в резервный ключ, а история/счётчики/настройки сохраняются.
- Автономный чат и эксперимент работают после отключения сети и reload.
- Опасное действие требует подтверждения; отмена не меняет мир.
- Ошибки/лимиты AI дают локальный ответ; выключение AI отменяет текущий запрос без лишней реплики.
- Тестовый API-ответ отображается как инертный текст, не исполняет HTML и не меняет хаос. Этот тест использует перехват сети, а не реального провайдера.
- Камера проверена на всех границах уровней. Проверены ширины 320, 360, 390, 768, 1024, 1440 и reduced motion.
- Визуально просмотрены реальные desktop/mobile скриншоты: docs/desktop-v2.png, docs/boris-desktop.png, docs/boris-mobile.png. Перекрытий/горизонтального переполнения в проверенных областях не выявлено.

## Исправленные проблемы

1. Незавершённые экспорты V2 world и отсутствующая интеграция лаборатории.
2. Зависание при бесконечном AI response stream: чтение ограничено по байтам, таймаут охватывает тело ответа.
3. Отсутствующий deadline лимитера: fail-closed.
4. Неполный AI-контекст и пустой активный протокол.
5. «Спросить Бориса» ошибочно попадал в знакомство по имени вместо оценки мира.
6. Безумие/раздражение нельзя было получить обычной игрой; теперь исходы экспериментов меняют настроение.
7. AI-ответ без mood сбрасывал настроение; теперь сохраняется актуальное, на критическом хаосе — паника.
8. Компонентный dev-harness не подходил production; заменён сценариями реального приложения.
9. Запись архива с датой из будущего подменяла отображаемый результат эксперимента; новая запись теперь выбирается по уникальному ID, без изменения хронологической сортировки. Регрессионный браузерный тест прошёл в production.

## Ограничения — не выдаются за пройденные проверки

- Нет реального Cloudflare-развёртывания, ключа и успешного ответа живого AI-провайдера. Серверный модуль проверен Node-тестами; workerd/Cloudflare runtime отдельно не подтверждён. По умолчанию AI выключен.
- Установка и запуск с иконки на физических Android/iPhone не проверялись. Chromium installability, manifest, офлайн и логика установки проверены автоматизацией; это не заменяет телефонный тест.
- Публичная публикация подтверждается отдельно после успешного GitHub Actions и проверки deployed-версии.
